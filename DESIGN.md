# Visual system
Operate mode. Three-column research workspace: controls, readable transcript, live execution inspector.
Graph geometry is functional and reflects compiled LangGraph edges. Charcoal surfaces, warm off-white
type, restrained amber for active execution, mint for validated evidence. No party-wide theme.
Typography: locally bundled Geist sans and mono. Mono only for IDs, measurements and graph nodes.
Left navigation lists, transcript on a single editorial surface, source disclosure beside each response.
Responsive: collapse columns into sequential regions; every control remains available on mobile.
All loading, error, empty, paused and complete states are explicit. Visible focus and reduced motion.
