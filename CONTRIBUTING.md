# Contributing

Use Python 3.12+ and Node 24. Run the offline backend suite, real pgvector test when available,
Ruff and Next.js build before submitting a change. Keep `.env`, runtime data, logs and downloaded
binary dependencies out of Git. Keep public source URLs and metadata traceable.

Do not add rankings, persuasion, election predictions, polling-based behavior or fabricated policy
positions. New candidates belong in configuration; policy claims belong in cited documents.
Fixture-only tests should remain independent from the political corpus and paid providers.
